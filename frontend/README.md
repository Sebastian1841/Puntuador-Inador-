# Frontend de Aftercredits

Vue 3 + TypeScript + Vite. Consulta `../README.md` para la arquitectura y la base de datos.

- `npm run dev`: inicia frontend y backend.
- `npm run dev:web`: inicia Vite con arranque autom?tico de la API Python.
- `npm run build`: comprueba tipos y genera `dist`.

El backend vive en `../backend`. Reinicia el servidor de desarrollo después de actualizar la estructura.
